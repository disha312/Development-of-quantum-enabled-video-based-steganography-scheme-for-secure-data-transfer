# AES Encryption Module

## Overview

This module implements the encryption component of the
Quantum-Enabled Video-Based Steganography project.

The encryption stage takes the video generated by the
steganography module and encrypts it using the Advanced
Encryption Standard (AES).

### Current Flow

Stego Video
    ↓
AES-256 Encryption
    ↓
Encrypted Video

The current implementation uses AES-256 in CBC mode.

---

## Features

- AES-256 encryption
- CBC (Cipher Block Chaining) mode
- Random Initialization Vector (IV)
- PKCS-style padding
- Binary video file encryption
- Encrypted output saved as a separate file
- Encryption testing using a sample video
