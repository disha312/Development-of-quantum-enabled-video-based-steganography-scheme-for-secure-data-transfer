# Quantum-Enabled Video Steganography – Encryption Module

## Overview

This module implements the **encryption component** of the
Quantum-Enabled Video-Based Steganography project.

The encryption stage takes the **stego video generated by the
steganography module** and encrypts it using **AES-256-GCM**.

The AES-256 encryption key is generated using the **BB84 Quantum Key
Distribution (QKD) module**.

### Current Encryption Flow

```text
Stego Video Input
        ↓
BB84 Quantum Key Distribution
        ↓
256-bit AES Key
        ↓
AES-256-GCM Encryption
        ↓
Encrypted Stego Video

```

File Description
my_qkd.py

Contains the BB84 Quantum Key Distribution implementation.

It: 

Generates random bits and bases.
Simulates quantum transmission.
Performs basis sifting.
Calculates QBER.
Checks for possible eavesdropping.
Applies SHA-256 privacy amplification.
Provides a 32-byte AES-256-ready key.

This file is used as the QKD key-generation component for the
encryption process.

encryption_gcm.py

Contains the main AES-256-GCM encryption function.

It:

Accepts binary data and a 32-byte key.
Generates a random 12-byte nonce.
Creates an AES-GCM cipher.
Encrypts the data.
Generates an authentication tag.
Stores the nonce, authentication tag, and ciphertext together.
encrypt_video_gcm.py

This is the main integration script.

It:

Takes the stego video as input.
Generates a key using the BB84 QKD module.
Obtains the 256-bit AES key.
Encrypts the stego video using AES-256-GCM.
Saves the encrypted video as a separate file.
Measures encryption time.
test_gcm.py

Used to test the AES-256-GCM encryption function with sample data.

It verifies that the encryption implementation produces ciphertext
successfully.

requirements.txt

Contains the Python dependencies required by the encryption and
integrated QKD module.

GCM Data Format

The encrypted output generated by this module is stored as:

Nonce + Authentication Tag + Ciphertext

The current implementation uses:

Nonce: 12 bytes
Authentication Tag: 16 bytes
AES Key: 32 bytes (256 bits)

Therefore, the encrypted output is 28 bytes larger than the
original input file.

Security

BB84 is used to generate the key material for the encryption stage.

The QKD process performs basis sifting and QBER checking before the
key is used.

AES-256-GCM provides:

Data confidentiality through AES encryption.
Authentication and integrity protection through GCM.
